## Usage

1. Run the provided installer script or manually copy the preset files to your IntelliJ IDEA configuration directory (typically `%APPDATA%\JetBrains\IntelliJIdea2023.1` on Windows).
2. For performance and system modules, launch the corresponding executable with administrator privileges.
3. Open the `Documentation` folder to review each tweak's purpose and apply them selectively.
4. Always use the backup utility before making changes to ensure a safe rollback.
